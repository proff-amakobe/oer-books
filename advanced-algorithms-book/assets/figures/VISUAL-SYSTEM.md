# Algorithms Figure Visual System

Canonical instructional figures are SVG files organized by chapter. They use a shared palette: deep navy `#17324D`, cobalt `#2563A6`, teal `#0F7C7B`, restrained amber `#C88719`, light gray `#EEF3F7`, and charcoal `#202A33`.

Default nodes use a light fill and navy outline. Active or path nodes use teal plus increased stroke weight; selected results use amber plus a distinct pale fill. Source and sink nodes use solid navy and teal. Directed edges use arrowheads; selected paths use teal and heavier strokes; residual/backward edges add dashes. Thus no state depends on color alone.

Labels use system sans-serif fonts, with monospace reserved for strings and coefficient vectors. Figures include SVG title and description elements, tight viewBoxes, and no external font or raster dependency.
