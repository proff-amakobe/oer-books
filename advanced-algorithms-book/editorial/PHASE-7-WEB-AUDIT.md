# Advanced Computational Algorithms
## Phase 7 — Web Architecture Baseline Audit

Audit date: 2026-08-29
Baseline commit: `dd7ebca` plus the completed, uncommitted Phase 6B print rescue
Public URL: <https://proff-amakobe.github.io/oer-books/advanced-algorithms-book/>

## Architecture

- Quarto `book` project with a shared `_quarto.yml` and `_book/` output.
- HTML used the Cosmo Bootstrap theme, Quarto sidebar/search/TOC, `styles/technical-blocks.css`, and `filters/technical-blocks.lua`.
- PDF uses dedicated TeX assets plus three Lua filters; `_quarto-print.yml` repeats the print format configuration.
- EPUB shares the semantic technical-block filter and CSS with HTML.
- The repository-level `.github/workflows/publish.yml` renders every book, assembles a `public/` tree, and deploys it with GitHub Pages Actions.
- No HTML-only profile, theme override, include, template, custom JavaScript, robots file, or explicit sitemap/SEO configuration existed.

## Structure and navigation

- Eight unnumbered front-matter pages precede five Quarto Parts and 15 numbered chapter files.
- References is unnumbered and present in navigation.
- Existing public chapter filenames produce the canonical 15 URLs and must remain unchanged.
- Rendered chapter numbering is 1–15 and the EPUB sequence is 1–15.
- Sidebar grouping follows the five Parts, but front matter had no visual group label and active state relied primarily on color.
- Right-side TOC and search were Quarto defaults.

## Presentation baseline

- Landing page was the manuscript Preface with no web-specific hero, book-structure overview, downloads, citation, or immediately visible edition identity.
- Technical semantics were already strong. The baseline HTML contains 513 semantic wrappers representing the 512 canonical Phase 6B blocks plus one renderer-level distinction.
- Copy buttons existed for 293 eligible source blocks but relied on Quarto's default title text.
- Fourteen canonical SVG instructional figures rendered without rasterization.
- Tables, chapter openers, callouts, typography, footer, focus state, and responsive behavior used mostly default theme styling.

## Publication and residue baseline

- Generated current HTML contained zero `First Edition` and zero `2025` matches.
- Source metadata used a deterministic `2026-01-01` publication date; no `date: today` or `date: last-modified` was active.
- One later-chapter learner template contains `[Your Name]`; it is pedagogical template content rather than publication administration.
- The former First Edition ISBN was not exposed as current metadata. Web-specific work should omit the unassigned Second Edition ISBN rather than display `ISBN: TBD`.

## Download and deployment baseline

- The public HTML had no PDF or EPUB action links.
- `_book/Advanced-Computational-Algorithms.pdf` and `.epub` are the correct public digital artifacts generated by Quarto. The production proof under `output/print/` remains a review artifact and will not be linked publicly.
- GitHub Pages deploys `_book/*`, so Quarto download links resolve to the public digital artifacts without exposing print-production paths.

## Phase 7 implementation boundary

Web changes are isolated in HTML configuration, `styles/web.scss`, HTML includes, deterministic post-render metadata, and `.web-only` landing content. The Preface remains `.print-only` for PDF/EPUB continuity. No TeX, print filter, print cover, Ingram, or printer geometry file is in Phase 7 scope.
