# Optional Figure Opportunities

Phase 4 deliberately limits new graphics to visuals with clear spatial or transformational value.

## High value

- Chapter 5: a semantic knapsack table with a highlighted backtracking path. This should be constructed as a native table, not an image.
- Chapter 9: a multi-stage augmenting-path sequence using one technically verified network, after the prose trace and implementation edge list are fully reconciled.
- Chapter 10: a KMP failure-transition figure that complements, rather than duplicates, the existing step trace.

## Optional

- Chapter 3: paired AVL single- and double-rotation diagrams.
- Chapter 4: activity-selection timeline and Huffman merge sequence.
- Chapter 6: randomized-pivot sampling and Monte Carlo versus Las Vegas comparison.
- Chapter 8: optimal versus approximate solution on one existing worked example.
- Chapter 11: a full FFT butterfly for a small fixed input, if the chapter later adds an explicit stage-by-stage trace.
- Chapter 12: segment-tree update propagation as a companion to the range-query figure.

## Decorative / do not add

- Generic AI, quantum-computer, blockchain, laptop, robot, or binary-background imagery.
- Pictures that merely repeat a chapter title or application list.
- Images of complexity tables, pseudocode, equations, terminal output, or project directory trees.
