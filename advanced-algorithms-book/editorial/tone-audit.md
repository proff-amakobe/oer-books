# Tone and Register Audit

The manuscript’s strongest voice is direct, energetic, and analogy-driven. Preserve that accessibility while removing transcript-like prompts, unsupported faux quotations, hype, and course-administration residue.

## Findings

The targeted phrase scan found **29 high-signal tone occurrences**. Examples:

| Example | Classification | Recommendation |
|---|---|---|
| “Here’s a wild fact” (Ch. 9) | GOOD PEDAGOGICAL HOOK | Tighten and support the equivalence claim |
| “Ready to dive in?” / “Ready to become … wizard?” | TIGHTEN | Replace repeated audience prompts with direct transitions |
| “seriously cool,” “boom,” “insultingly simple” | REWRITE FORMALLY | Retain energy without trivializing the topic |
| Repeated “magic” headings/explanations | TIGHTEN | Use sparingly for intuition, then name the mechanism |
| “Every competitive programmer ever” | PSEUDO-QUOTE / REMOVE | Unsourced faux attribution |
| “Every algorithm researcher ever” | PSEUDO-QUOTE / REMOVE | Unsourced faux attribution |
| “Ancient programmer wisdom” | HUMOROUS DEVICE / REVIEW | Keep only if clearly framed and not used as authority |
| “Fifteen weeks ago” (two occurrences) | REMOVE | Couples the book to one course calendar |

A broader course-schedule scan found **102 lines** containing course/week/presentation/submission/grade/instructor language. Not all are defects, but all need editorial triage. Chapter 15 contains the densest course-specific residue; Chapter 1 also includes a late-policy placeholder and course environment naming.

Target register: an excellent professor explaining difficult ideas clearly. Use hooks, concrete examples, and occasional humor; follow them immediately with precise terminology and evidence.
