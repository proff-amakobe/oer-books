# Print Cover Production Note

The repository cover artwork is a front-cover identity asset, not a printer-ready wraparound cover.

A final full cover must be generated only after the printer provides its production template and the following values are fixed:

- final 8.5 × 11 inch trim specification;
- final interior page count;
- paper stock and caliper;
- calculated spine width;
- required 0.125-inch bleed and safe zones; and
- barcode/ISBN placement requirements.

Do not estimate the spine width from the current draft. Export the final interior first, then use the selected printer's calculator and template.
